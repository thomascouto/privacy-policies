# privacy-policies

Privacy policies for the apps published by TCGR IT Systems LTDA, served by GitHub Pages at
<https://thomascouto.github.io/privacy-policies/>.

Each app has its own folder, and its `index.md` is the policy page. Add a new app by creating a
folder and linking it from the root `index.md`.

|-----|--------|
